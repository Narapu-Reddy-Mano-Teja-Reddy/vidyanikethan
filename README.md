# Vidyaniketan Jr College Website

A modern, fully responsive educational website developed for **Vidyaniketan Jr College, V.Kota**. The website is designed to provide students, parents, and visitors with an engaging digital experience while showcasing the institution's academic excellence, courses, facilities, leadership, and campus life.

## 📖 About the Project

The Vidyaniketan Jr College website has been designed with a modern, professional, and user-friendly interface to reflect the institution's commitment to quality education.

The website includes dedicated pages for:

- Home
- About
- Courses
- Gallery
- Leadership
- Contact

It highlights the college's Intermediate programs:

- MPC (Mathematics, Physics & Chemistry)
- BiPC (Biology, Physics & Chemistry)
- MEC (Mathematics, Economics & Commerce)
- CEC (Civics, Economics & Commerce)

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/vidyaniketan-jr-college.git
```

Navigate to the project

```bash
cd vidyaniketan-jr-college
```

Open the project using your preferred code editor.

Run the website using a Live Server extension or any local development server.
